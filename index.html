Reflective Diagnostics

Research Instrument Overview
CLASSIFICATION: PUBLIC
DOC TYPE: OVERVIEW
DATE: 2026-03-10
This tool does not use AI. A rule-based research instrument for evaluating reasoning in AI systems.

Uses explicit evaluation rules to generate structured evidence on correctness, confidence, and reliability.

Most AI systems are judged by how convincing they sound. This instrument is designed to test how reliable they actually are.

1.0 Questions It Can Answer

  • Can we trust this model when the answer matters?
  • Does the model know when it may be wrong?
  • Which model performs best for my specific task?

2.0 What It Produces

The instrument turns model behavior into structured, reviewable evidence.

  • A trust signal for model reliability.
  • A task-specific model selection signal.
  • A traceable JSON record.
  • A built-in ground-truth benchmark.
  • A reproducible evaluation framework.

3.0 What It Gives You

  • Independent evaluation without requiring access to model internals.
  • Structured datasets at scale for research and analysis.
  • A flexible framework for testing new hypotheses across models and tasks.

4.0 Research Applications

  • Comparative evaluation of AI systems.
  • Hypothesis testing across models and tasks.
  • Reproducible evaluation studies.

5.0 How It Differs

Reflective Diagnostics is not a training method and not just a benchmark. It is a rule-based audit instrument for reasoning reliability.

System Class Designed To Rule-Based Measures Final Answer Only? Produces Evidence Record? Can Localize Failure?
Training methods Change model behavior No No No No
Benchmarks Score performance Partial Usually yes Rarely Limited
Eval frameworks Run eval workflows Mixed Depends Partial Partial
Judge-based evaluators Grade outputs No Usually yes Limited Limited
Reflective Diagnostics Audit reasoning reliability Yes No Yes Yes

Each run produces structured evidence, including scorecards, failure signals, and JSON records for review and downstream analysis.
